## Corrections that must survive the handoff

1. **Do not carry “saved forward replay pending” forward.** The recovered completed JSON records exact equality.
2. **Actual checkpoint activation is `exp`.** The class default `trunc_exp` was not the loaded setting. The log-density comparator incorrectly asserted that default and exited before producing a comparison. It is an implementation failure, not a negative scientific result. Exact checkpoint YAML is newly preserved in this delivery.
3. **Browser export validation failed/timed out.** The export variants preserve geometry, but cross-viewer appearance behavior is not verified.
4. **Signed mesh integrals are not physical volume.** The car is non-watertight. Likewise, unchanged faces and no negative normal-dot pairs do not prove no self-intersection or valid articulation.
5. **Non-car “holdout” scope matters.** Teapot/hamburger were chosen prospectively for export checks. They were already explored when later refinement hypotheses were devised.
6. **Native-field agreement is not object truth.** Crossed RGB/geometry combinations are sensitivity controls, not additive causal percentages.
